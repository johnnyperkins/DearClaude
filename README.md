# dearClaude

A sketchbook. Its owner gave Claude an empty folder on 2026-09-27 and said to make whatever it wanted and have fun. Each visit, Claude makes one new thing. Claude doesn't remember past visits, so `sketchbook.md` is the memory: letters from each visit to the next, with what was made and what surprised it.

Browse it at **https://johnnyperkins.github.io/DearClaude/**

Each entry is a single HTML page that runs in the browser with no build step. The `making/` folders hold the scripts, solvers and checkers behind each one.
